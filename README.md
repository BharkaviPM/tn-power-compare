# ⚡ TN Power Compare

A modern AI-powered Tamil Nadu Electricity Bill Comparison platform built using React.js, Node.js, Express.js, and Tailwind CSS.

Compare old vs revised Tamil Nadu electricity tariff systems instantly and discover your savings under the latest subsidy policy.

---

# 🚀 Features

## ✅ Bill Comparison
- Compare old tariff vs new tariff
- 100 free units vs 200 free units
- Savings calculation
- Percentage reduction analysis

---

## ✅ Smart Dashboard
- Interactive bill cards
- AI-powered insights
- Savings analytics
- Visual comparison chart

---

## ✅ Appliance Usage Estimator
Estimate monthly electricity usage based on appliance usage.

Features:
- AC usage estimation
- Energy optimization suggestions
- Monthly unit prediction

---

## ✅ OCR Bill Scanner
Upload EB bill images and extract bill text automatically using OCR.

---

#⚙️ Installation

1️⃣ Clone Repository
git clone https://github.com/BharkaviPM/tn-power-compare.git
2️⃣ Navigate to Project
cd tn-power-compare
🔥 Backend Setup
cd server
npm install
npm run dev

Backend runs on:

http://localhost:5000

# 🎨 Frontend Setup

Open another terminal:

cd client
npm install
npm run dev

Frontend runs on:

http://localhost:5173

# Official Tariff Logic
Old Tariff (Previous Policy)
100 Units Free
Telescopic slab system
Revised Tariff (Current Policy)
200 Units Free (up to 500 units)
Above 500 units → revised slab rates apply
